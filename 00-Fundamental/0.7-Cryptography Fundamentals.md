# 🔐 Cryptography
Cryptography protects information by converting readable data into a secure format that only authorized parties can access.
It supports confidentiality, integrity, and authentication in modern systems.

# 📄 Plaintext & 🔒 Ciphertext
- **Plaintext** is readable data before encryption.
- **Ciphertext** is encrypted data that cannot be understood without the correct key.

# 🔄 Encryption & Decryption
Encryption converts Plaintext into Ciphertext.
Decryption restores Ciphertext back to Plaintext using the correct key.

# 🔧 Cipher & 🗝️ Cryptographic Key
A Cipher is the algorithm used to perform encryption and decryption.
A Cryptographic Key is the secret value used by the cipher to protect data.

---

# 🔑 Encryption Methods
## Symmetric Encryption
Uses the same key for encryption and decryption.
**Advantages**
- Fast
- Efficient
- Suitable for large amounts of data
**Limitation**
- Secure key sharing is required.

---

## Asymmetric Encryption
Uses a Public Key for encryption and a Private Key for decryption.
**Advantages**
- Secure key exchange
- Supports digital identity
**Limitation**
- Slower than symmetric encryption.

---

### #️⃣ Hash
Hashing converts data into a fixed-length value.
Unlike encryption, hashing is designed to be one-way and is commonly used for password storage and integrity verification.

### 🧂 Salt
Salt is random data added before hashing a password.
It helps prevent identical passwords from generating identical hashes and improves password security.

### ✍️ Digital Signature
A Digital Signature verifies the authenticity and integrity of data.
It helps confirm that data comes from the expected sender and has not been modified.

### 📜 Digital Certificate
A Digital Certificate links an identity to a Public Key.
Certificates are commonly used by websites to prove their identity during secure connections.

---

### 🌐 HTTPS & 🔐 TLS
HTTPS protects web communication using TLS.
TLS encrypts data exchanged between clients and servers to prevent unauthorized access.

### 🏛️ Public Key Infrastructure (PKI)
PKI is the framework responsible for managing Digital Certificates and establishing trust between communicating parties.

### 🛡️ Security Controls
- HTTPS
- Strong Cryptography
- Password Hashing
- Salt
- Secure Key Management
- Digital Certificates

---

# 📌 Key Takeaways
- Cryptography protects sensitive information.
- Encryption and Hashing serve different purposes.
- Symmetric and Asymmetric Encryption solve different security problems.
- Digital Signatures and Certificates establish trust.
- HTTPS relies on TLS to secure communication.
- PKI provides the trust framework for Digital Certificates.
