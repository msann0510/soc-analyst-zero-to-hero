# ⚔️ Cyber Kill Chain
Cyber Kill Chain is a security model that describes the common stages of a cyber attack, from gathering information about a target to achieving the attacker's objective.
Understanding the Kill Chain helps defenders identify where an attack is occurring and stop it before it progresses further.

---

# 🔍 Reconnaissance
Reconnaissance is the information gathering stage.
Attackers collect publicly available information about the target, such as email addresses, domains, employees, or technologies used by the organization.

# 🛠️ Weaponization
Weaponization is the preparation stage.
Attackers create or modify malicious payloads, phishing emails, or exploit tools that will be used against the target.

# 📧 Delivery
Delivery is the stage where the attacker sends the payload to the victim.
Common delivery methods include phishing emails, malicious attachments, fake websites, and infected USB devices.

# 💥 Exploitation
Exploitation occurs when the attacker successfully exploits a vulnerability or tricks the victim into executing malicious content.
Examples include opening a malicious attachment or entering credentials on a fake login page.

# 💾 Installation
Installation is the stage where malware or another malicious component is installed on the victim's system.
This allows the attacker to maintain access for future actions.

# 📡 Command & Control (C2)
Command & Control (C2) is the communication channel between the compromised system and the attacker's infrastructure.
Through C2, attackers can send commands, receive information, and control infected devices remotely.

# 🎯 Actions on Objectives
This is the final stage of the attack.
The attacker performs the intended objective, such as:
- Stealing sensitive data
- Encrypting files with ransomware
- Destroying information
- Exfiltrating credentials

---

# 🗺️ MITRE ATT&CK
MITRE ATT&CK is a globally recognized knowledge base that documents real-world attacker behavior.
It helps security professionals understand how attackers operate and improve detection and response capabilities.

---

# 🎯 Tactic
A Tactic represents the attacker's objective or goal during a stage of an attack.
Examples include:
- Initial Access
- Credential Access
- Discovery
- Lateral Movement
- Exfiltration

# 🛠️ Technique
A Technique is the method used by an attacker to achieve a specific Tactic.
Multiple Techniques may exist for the same Tactic.
For example, Credential Access may be achieved through phishing, keylogging, or password spraying.

# 📄 Procedure
Within MITRE ATT&CK, a Procedure is the real-world implementation of a Technique by a threat actor.
Different attackers may use different Procedures while applying the same Technique.

---

# 🛡️ Security Controls
Examples of security controls used throughout the Cyber Kill Chain include:
- Email Filtering
- Security Awareness Training
- Patch Management
- Endpoint Detection and Response (EDR)
- Firewall
- Network Monitoring
- Backup
- Incident Response

---

# 📌 Key Takeaways
- Cyber Kill Chain explains the stages of a cyber attack.
- MITRE ATT&CK documents real-world attacker behavior.
- Tactics describe goals, Techniques describe methods, and Procedures describe real-world implementations.
- Security teams aim to detect and stop attacks as early as possible in the Kill Chain.
- MITRE ATT&CK is widely used by SOC Analysts to understand attacker behavior and improve detection strategies.
