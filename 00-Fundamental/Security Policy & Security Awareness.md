# 📜 Security Policy & Security Awareness

## 🎯 Learning Objectives

After completing this lesson, I can:

- Explain the purpose of Security Policy.
- Differentiate Policy, Standard, Procedure, and Guideline.
- Understand Acceptable Use Policy (AUP).
- Explain the importance of Security Awareness and Security Training.
- Identify Human Error and Insider Threat.
- Understand common human-focused security controls.

---

# 📜 Security Policy

Security Policy defines the organization's security rules, objectives, and expectations.

It provides the foundation for protecting information assets.

---

### 📏 Standard
A Standard defines the minimum technical or operational requirements needed to enforce a Security Policy.
### 📋 Procedure
A Procedure describes the step-by-step process required to perform a task securely and consistently.
### 📝 Guideline
A Guideline provides recommended best practices that improve security but are generally not mandatory.
### 📄 Acceptable Use Policy (AUP)
An Acceptable Use Policy defines how users are allowed to use organizational systems, devices, and network resources.
Examples include restrictions on software installation, password sharing, and unauthorized device usage.

---

# 🎓 Security Awareness
Security Awareness improves employees' understanding of common cyber threats and secure behaviors.
It helps users recognize risks before incidents occur.

# 🎯 Security Training
Security Training develops practical security skills through structured education and exercises.
Unlike awareness, training focuses on how to perform security-related tasks correctly.

---

# 👤 Human Error
Human Error refers to unintentional mistakes that increase security risks.
Examples include clicking phishing links, weak passwords, and accidental data exposure.

---

# 🕵️ Insider Threat
An Insider Threat originates from individuals with legitimate access to organizational resources.
Types include:
- Malicious Insider, People who intentionally commit dangerous acts.
- Negligent Insider, A person who has no malicious intent but commits an error that leads to a security incident.
- Compromised Insider A person whose account has been successfully taken over by an attacker.

---

# 🧹 Clean Desk Policy
A Clean Desk Policy reduces the risk of exposing sensitive information by requiring users to secure documents and lock their devices when unattended.

# 🔑 Password Policy
A Password Policy defines organizational password requirements such as:
- Minimum length
- Complexity
- Password reuse restrictions
- Secure password handling

---

# 🛡️ Human-Based Security Controls
Examples include:
- Security Awareness
- Security Training
- Acceptable Use Policy
- Password Policy
- Clean Desk Policy
These controls reduce risks caused by Human Error and Insider Threats.

# 📌 Key Takeaways

- Security depends on both technology and people.
- Policies establish security expectations.
- Awareness and training improve secure behavior.
- Insider Threats can be intentional or unintentional.
- Human-focused security controls are essential for reducing organizational risk.
